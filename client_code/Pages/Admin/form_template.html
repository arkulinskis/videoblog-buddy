YouTube upload

With a Google OAuth client ID, members upload straight from the publish kit: video, thumbnail and captions. Each person signs in with their own Google account in a popup; the video goes from their browser to YouTube, never through this app.

Set it up (about 5 minutes)

  1. Open Google Cloud console and create a project, e.g. “VideoBlog Buddy”.
  2. APIs & Services → Library → YouTube Data API v3 → Enable.
  3. Google Auth Platform (OAuth consent screen): app name, your email, audience External. While it's in Testing, add each person who will upload as a test user.
  4. Clients → Create client → Web application. Under Authorized JavaScript origins add (and any other address the app runs on).
  5. Copy the Client ID (not the secret) into the box above and save.

Good to know: until Google audits the project, YouTube keeps videos uploaded through the API private; switch them to public in YouTube Studio (or ask for an audit with Google's YouTube API audit form). Custom thumbnails need a verified channel (youtube.com/verify). Each project gets about 6 uploads a day on the free quota.

The listing text, the permission answers, the images and a store-ready zip are in the project folder: extension/store/ (see PUBLISH.md).
